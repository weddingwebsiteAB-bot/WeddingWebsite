ALFRED & BIANCA — WEDDING WEBSITE

Open index.html in a modern web browser to preview the website.
Keep the assets folder beside index.html; it contains the supplied wedding reference images and the custom watercolor floral background.

DESIGN UPDATE
The site now uses a soft watercolor floral background in white, olive green, and butter yellow. The background is decorative and does not replace or alter the supplied church, venue, or attire images.

To publish, upload the complete folder contents to your web host (or a static hosting service). Do not upload index.html by itself; the assets folder is required.

The Google Fonts import requires an internet connection. All local images are included in assets.
